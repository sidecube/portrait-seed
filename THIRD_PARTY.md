# External components

This repository contains original/adapted project code under MIT. It does not
vendor dependencies, pretrained weights, model projectors or runtime binaries.

Install dependencies from their publishers and retain their licenses when
redistributing them: Python, Pillow, HTTPX, the OpenAI Python SDK, NumPy and
OpenCV (including licenses/notices bundled with the specific wheel).

The separately installed [llama.cpp](https://github.com/ggml-org/llama.cpp) runtime
and [Qwen model](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF) have their own
licenses. Review the exact model card and downloaded files; this repository's
MIT license does not relicense weights or an API service.

The overview illustration was generated for this package using OpenAI's built-in
image generation tool without a real visitor photo. Other diagrams were authored
as SVG. They may be reused with this documentation; no exclusivity or copyright
protection of AI-generated imagery is asserted.
