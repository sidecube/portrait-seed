# Security and privacy reports

Do not attach visitor photos, generated personal collections, raw API responses,
API keys, .env files or databases to a public issue. Describe the failure using
the safe error code, dependency versions and a synthetic reproduction.

For a suspected data disclosure, use the repository's private vulnerability
reporting feature if the publisher enabled it; otherwise ask the maintainer for
a private contact without disclosing the sensitive material publicly.

The trust boundaries and limitations are documented in docs/PRIVACY.md.
The source is educational and reusable; no external security audit is claimed.
